# 실제 Supabase 통합 점검 체크리스트

자동 테스트는 가짜 Supabase(`tests/e2e/fake-supabase.js`)와 로컬 Postgres로 돌아가요.
여기 있는 항목은 **실제 Supabase 클라우드 + 실제 휴대폰**에서만 확인할 수 있는 것들이에요.
크게 바꾼 뒤나 DB 업데이트·함수 배포 뒤에 한 번씩 확인해 주세요.

- 소요 시간: 처음엔 1시간쯤, 익숙해지면 20~30분
- 표시: `[ ]` 확인 전 · `[x]` 정상 · 문제가 있으면 줄 끝에 날짜와 증상을 적어 두기

---

## 0. 준비

**계정·기기**
- 계정 **A**(가계부 주인)와 계정 **B**(참여자): 이메일 두 개
- 기기 **두 대 이상**: 휴대폰 1대(홈 화면에 설치한 앱) + PC 브라우저 1개 이상
  - 아이폰은 "공유 → 홈 화면에 추가"로 설치한 앱에서만 푸시가 돼요
- 휴대폰의 와이파이·모바일 데이터를 끌 수 있어야 함(오프라인 확인)

**서버 설정 확인 (Supabase 대시보드)**
- [ ] SQL: `supabase/` 업데이트 파일을 017까지 모두 실행함 (앱 위쪽에 "DB 업데이트가 필요해요" 안내가 없으면 정상)
- [ ] Edge Functions: `push-notify`가 최신으로 배포됨 (`supabase functions deploy push-notify --no-verify-jwt`)
- [ ] 함수 비밀 값: `VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`, `WEBHOOK_SECRET`
- [ ] Database Webhooks 3개(INSERT): `transactions`, `shopping_items`, `tx_comments` → `push-notify`, 헤더 `x-webhook-secret`
- [ ] (리포트를 쓰면) `009_report_schedule.sql` 실행, Database → Cron Jobs에 `ledger-weekly-report`·`ledger-monthly-report`가 있음
- [ ] Vercel 환경 변수: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_VAPID_PUBLIC_KEY`
- [ ] GitHub Actions → keepalive를 "Run workflow"로 한 번 실행해서 초록색 ✓

## 1. 로그인·계정

- [ ] A로 회원가입 → 확인 메일의 링크 → 앱으로 돌아와 로그인됨
- [ ] 로그아웃 → 다시 로그인 (자동 로그인 끔/켬 둘 다)
- [ ] 비밀번호 재설정 메일 → 링크 → 새 비밀번호로 로그인
- [ ] 설정 → 계정·개인정보 → 개인정보 처리방침이 열리고, 운영자 연락처가 비어 있지 않음

## 2. 기본 입력과 동기화 (A, 기기 두 대)

- [ ] 휴대폰에서 지출 입력 → PC 화면에 **새로고침 없이** 몇 초 안에 나타남
- [ ] PC에서 그 내역 수정 → 휴대폰에 반영됨
- [ ] 휴대폰에서 그 내역 삭제 → PC에서도 **새로고침 없이** 사라짐
- [ ] 장보기 물품 추가·담기·삭제도 두 기기에 똑같이 반영됨
- [ ] 설정(예산, 즐겨찾기, 카테고리) 변경도 다른 기기에 반영됨

## 3. 오프라인 입력 (휴대폰)

- [ ] 비행기 모드로 지출 2건 입력 → 화면에 바로 보이고 "연결되면 자동으로 올라가요" 안내
- [ ] 앱을 완전히 닫았다가 비행기 모드인 채로 다시 열기 → 2건이 그대로 있음
- [ ] 비행기 모드 해제 → 몇 초 안에 서버로 올라가고, PC에서 **2건만** 보임(중복 없음)
- [ ] 오프라인 상태에서 앱을 처음 여는 화면도 뜸(서비스워커), 내역 탭·장보기 탭·리포트 탭이 열림

## 4. 동시에 고칠 때 (017)

- [ ] 두 기기에서 같은 내역의 수정 창을 열고, 기기1에서 금액을 바꿔 저장 → 기기2에서 메모를 바꿔 저장
  → 기기2에 "다른 기기에서 먼저 바뀌었어요" 알림, "내 것으로 저장"을 누르면 기기2 내용으로 저장됨
- [ ] 기기1에서 내역을 지운 뒤, 이미 열려 있던 기기2 수정 창에서 저장 → "다시 살리기" 알림
- [ ] 두 기기에서 **서로 다른** 즐겨찾기를 거의 동시에 하나씩 추가 → 알림 없이 둘 다 남음(자동 합치기)

## 5. 공유 가계부 (A 주인, B 참여)

- [ ] A: 가계부 공유 → 초대 코드(10자리) 만들기, 초대 링크 복사
- [ ] B: 링크로 열기 → 로그인 후 공유 화면에 코드가 채워져 있음 → "나는 누구"를 고르고 참여
- [ ] 참여한 B에게 **A의 가계부만** 보이고, B의 원래 내역은 안 보임
- [ ] B가 입력한 내역이 A에게 보이고, 반대도 됨
- [ ] 같은 초대 코드로 다시 참여하려 하면 "이미 사용된 초대 코드" 안내
- [ ] B가 보낼 목록이 남아 있을 때(오프라인 입력 직후) 참여·나가기 버튼이 막혀 있음
- [ ] B가 나가기 → B의 원래 가계부가 다시 보이고, 공유 가계부 사본은 B 기기에서 사라짐
- [ ] A가 B를 내보내기 → B가 앱으로 돌아오면 자기 가계부로 바뀜
- [ ] 주인 A는 내보내기 목록에 없음(내보낼 수 없음)

## 6. 댓글

- [ ] B가 A의 내역에 댓글 → A 화면에 실시간으로 나타남, 이름이 B가 고른 "사람" 이름으로 보임
- [ ] 자기 댓글만 삭제 버튼이 보이고, 지우면 상대 화면에서도 사라짐
- [ ] 오프라인에서는 댓글 입력칸이 꺼져 있음

## 7. 푸시 알림 (휴대폰, 앱을 닫거나 다른 앱을 보는 상태)

- [ ] 설정 → 알림 → 웹 푸시 켜기 → 권한 허용 → "켜짐"
- [ ] PC에서 지출 입력 → 휴대폰에 "○○님이 지출을 추가했어요" 푸시
- [ ] **같은 휴대폰**에서 입력한 내역은 그 휴대폰에 푸시가 오지 않음
- [ ] 장보기 물품 추가 → 푸시, 알림을 누르면 장보기 탭으로 열림
- [ ] 장보기 "물품별로 나누기"로 여러 개 결제 → 푸시가 **하나로** 묶여 옴
- [ ] 같은 날 장보기 결제를 두 번(몇 분 간격) → 휴대폰을 껐다 켜도 결제 알림이 **두 개** 남음
- [ ] 댓글 → 푸시, 누르면 그 내역 수정 화면이 열림. 댓글 쓴 사람의 기기에는 오지 않음
- [ ] 알림 설정에서 "내역 추가"를 끄면 내역 푸시가 안 옴(장보기는 옴)
- [ ] 방해 금지 시간을 지금 시각이 포함되게 설정 → 푸시가 안 옴, 앱을 열면 배너는 보임
- [ ] 앱을 보고 있는 동안에는 시스템 알림 대신 화면 위 배너만 뜸
- [ ] 로그아웃하면 그 기기로 더 이상 푸시가 오지 않음
- [ ] (리포트) SQL Editor에서 `select public.send_report_push('week');` → 지난주 내역이 있으면 "지난주 지출 ○원" 푸시

## 8. 반복 내역

- [ ] 오늘 날짜의 반복 내역 추가 → 바로 내역에 🔁 표시로 기록됨, 다른 기기에서도 **한 번만** 보임
- [ ] 두 기기를 동시에 열어 둔 채 자정을 넘기기(또는 다음 날 두 기기 모두 열기) → 그달 1일 반복 내역이 **한 번만** 기록됨
- [ ] 자동 기록된 반복 내역을 지움 → 다시 생기지 않음
- [ ] 일시정지 → 다시 시작 → 멈춰 있던 달은 기록되지 않음
- [ ] 사람이 둘 이상이면 반복 내역 화면이 "나 → 다른 사람 → 공동"으로 묶이고, 묶음마다 매달 합계가 보임
- [ ] 말일 결제(결제일 31일) 반복 내역이 있는 상태에서, 다음 달 1일에 같은 메모로 직접 입력
  → "결제가 말일이 아니라 ○월 1일에 들어왔어요… 자동 기록을 멈췄어요" 알림, 반복 내역 화면에 ⚠️ 이유

## 8-1. 결제 문자로 입력 (휴대폰)

- [ ] 카드 결제 문자를 길게 눌러 복사 → 새 내역 창 "📋 결제 문자 붙여넣기" → (아이폰은 "붙여넣기" 허용) 금액·날짜·가맹점·카드가 채워지고 저장은 직접 누름
- [ ] 클립보드를 못 읽으면 붙여 넣는 칸이 열리고, 붙여 넣은 뒤 "읽기"로 채워짐
- [ ] 안드로이드: 홈 화면에 설치한 앱에서, 문자 앱의 결제 문자 "공유" → 목록에 "가계부"가 보이고 누르면 채워진 입력 창이 열림
- [ ] 쓰는 카드사의 문자 형식이 잘 읽히는지 (안 되는 문구는 개인정보를 지우고 모아 두기)

## 9. 장보기·카드

- [ ] 장바구니 → 결제 확정(한 건으로 합치기) → 가계부에 1건, 결제 버튼을 빠르게 두 번 눌러도 1건
- [ ] 결제 카드를 고르면 그 카드 청구 예정에 잡히고, 다음 결제 때 그 카드가 기본으로 선택됨
- [ ] 카드 등록(마감일·결제일) → 할부 3개월 지출 → "카드 결제 예정"에 3개월로 나뉘어 보임

## 10. 카테고리·백업·변경 기록

- [ ] 카테고리 이름 바꾸기(내역 수십 건) → 모든 기기에서 새 이름, 변경 기록에 내역마다 쌓이지 않음
- [ ] 두 카테고리 이름 맞바꾸기(식비↔교통) → 내역이 섞이지 않음
- [ ] 백업 파일 받기 → 내역 몇 건 삭제 → "빠진 것만" 복원 → 지운 것만 돌아옴, 푸시가 쏟아지지 않음
- [ ] 변경 기록에서 지운 내역 "되살리기", 수정한 내역 "되돌리기"

## 11. 앱 업데이트·화면

- [ ] 앱을 켜 둔 채 새 버전을 배포 → 화면으로 돌아오거나 30분 안에 "새 버전이 있어요 · 새로고침" 표시
- [ ] 설정 → 화면 테마 "어둡게/밝게/기기 설정"이 바로 바뀌고 새로고침해도 유지됨
- [ ] 홈 화면 앱 아이콘 길게 누르기 → "지출 추가"·"내역 보기"·"장보기 목록" 바로가기 동작

## 12. 회원 탈퇴 (테스트 계정으로만!)

- [ ] 참여자가 있는 가계부의 주인(A)이 탈퇴 → "참여자를 먼저 내보내 주세요"로 거절
- [ ] 참여자를 내보낸 뒤 탈퇴 → 로그아웃되고 같은 이메일로 다시 가입하면 빈 가계부
